# videotext baseline

Этот набор фиксирует входные условия перед schema v4 и двуязычным pipeline.
Fixtures синтетические и не содержат пользовательских медиа или расшифровок.

Зафиксированные классы ошибок по реальным журналам версии 0.4.2:

- Whisper SRT может содержать служебные cue нулевой длительности; они должны
  исключаться с отчетом, а обратный диапазон должен оставаться ошибкой.
- Описание темы может несколько раз повторить предыдущее название; повтор
  одного description не должен уничтожать остальные рассчитанные диапазоны.
- Фиксированные веса общего прогресса не отражают время Whisper и Ollama.

Наблюдавшиеся диапазоны длительности операций на длинных локальных видео:

- Whisper: примерно 30-50 минут для видео длительностью 113-169 минут;
- тематический анализ: примерно 4-23 минуты;
- прожиг субтитров в 169-минутное видео: примерно 22 минуты.

`legacy_manifest_v3.json` используется только для проверки совместимости и
перед запуском probe получает временные пути source/project.
